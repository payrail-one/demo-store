# Aurora image assets

These original campaign and catalog images were generated for the Payrail demo store with OpenAI's built-in image generation tool on 2026-10-03. They contain no third-party logos, text, or source photography.

Shared direction: photorealistic premium Scandinavian/Japanese homeware photography; quiet editorial composition; natural materials; soft directional daylight; no people, logos, text, or watermark.

- `aurora-hero.webp`: modernist limestone living room with the frosted Orbit Lamp, ceramic cup, and notebook; wide composition with negative space for campaign copy.
- `orbit-lamp.webp`: single frosted glass mushroom lamp on a warm ivory studio background.
- `field-notebook.webp`: single thread-bound linen notebook with blank cream pages on sand.
- `arc-speaker.webp`: single oval charcoal textile speaker on graphite.
- `mineral-cup.webp`: single handmade mineral-glaze cup on terracotta.
- `pebble-vase.webp`: single asymmetric chalk ceramic vase on pale sage.
- `linen-throw.webp`: single folded natural linen throw on olive-grey.
- `stone-tray.webp`: single honed travertine tray on warm chalk.
- `cedar-incense.webp`: single dark cedar incense rest with an aged-brass detail on smoked brown.

The generated PNG masters remain outside the repository. Web assets are resized and encoded as WebP for production delivery.
